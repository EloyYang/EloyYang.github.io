표시 모양

8방향, 다이얼 하나에 앱 8개

다이얼을 누르면 지정한 앱 아이콘이 손가락 주위에 펼쳐지고, 끄는 방향의 아이콘이 커지며 빛납니다. 손을 떼면 실행. 방향은 손가락을 댄 자리에서부터 재기 때문에 다이얼이 커도 조금만 끌면 됩니다.

  • 원하는 위치에 다이얼을 여러 개 놓을 수 있어요
  • 크기와 표시 모양(투명 · 원 · 링 · 사각 · 점)을 고를 수 있어요
  • 방향이 바뀔 때마다 짧은 진동으로 알려 줘요

위로 쓸어 올리면 검색

다이얼에 없는 앱은 홈 화면을 위로 쓸어 올려 바로 찾습니다. 앱뿐 아니라 설정 화면도 검색돼요.

  • 즐겨찾기와 자주 찾는 항목이 맨 위에
  • 오른쪽 초성 · 알파벳 인덱스를 끌어 빠르게 이동
  • 앱에 별명을 붙여 그 이름으로도 찾을 수 있어요

개인정보를 모으지 않습니다

광고나 분석 도구가 없습니다. 설치된 앱 목록과 홈 화면 구성은 기기 안에서만 쓰고, 인터넷은 새 버전을 확인하고 내려받을 때만 씁니다. 자세한 내용은 개인정보처리방침을 보세요.

설치하기

  1. APK 내려받기휴대폰에서 아래 버튼을 눌러 DialHome.apk를 받습니다.
  2. 설치 허용처음이면 브라우저(또는 파일 앱)에 '출처를 알 수 없는 앱 설치'를 허용합니다.
  3. 기본 홈 앱으로설치 후 홈 버튼을 누르고 다이얼 홈을 고르거나, 설정 › 애플리케이션 › 기본 앱 › 홈 앱에서 바꿉니다.
  4. 다이얼 놓기홈 화면을 길게 눌러 편집을 열고, 다이얼을 놓은 뒤 눌러서 방향마다 앱을 지정합니다.
